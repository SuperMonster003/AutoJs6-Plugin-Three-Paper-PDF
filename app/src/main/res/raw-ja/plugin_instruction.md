3-Paper PDF は AutoJs6 のスクリプトに `pdf` モジュールを提供し, PDF ファイルの読み込み, レンダリング, 結合, 分割, 生成, 暗号化を行えるようにします. 単独で使える PDF ビューアーとツールボックスでもあり, AutoJs6 がなくても使えます.

### はじめに

1. AutoJs6 のスクリプトでグローバルモジュール `pdf` をそのまま使います. 例は下記を参照してください.
2. スマートフォンで PDF を表示または処理するには, ランチャーから 3-Paper PDF を開き, 求められたらすべてのファイルへのアクセスを許可してから, "PDF を開く" をタップするか "ツール" で必要な処理を選びます.
3. AutoJs6 のファイルマネージャーで PDF ファイルをタップすると, 3-Paper PDF のビューアーで開きます.

### 主な機能

- **読み込み**: ページ数, ページサイズ, メタデータ, 暗号化の状態. ページごとのテキストとアウトライン (しおり). テキスト検索. 埋め込み画像の一覧と書き出し.
- **レンダリング**: ページを画像オブジェクトまたは PNG / JPEG / WebP ファイルにします. サイズは dpi, 拡大率, 目標の幅と高さで指定できます.
- **ページ操作**: 結合 (しおりを保持), 分割, 抽出, 削除, 並べ替え, 回転.
- **生成と暗号化**: 画像, テキスト, HTML から PDF を生成します. 文書にパスワードと権限を設定するか, パスワードを解除します.
- **スキャンページの認識**: インストール済みの OCR プラグインを使って, テキストレイヤーのないスキャンページの文字を認識します.
- **ビューアー**: 連続スクロール, ピンチズーム, サムネイル, アウトライン, 検索結果のハイライト, ページ移動, ナイトモード. 他のアプリから "アプリで開く" や共有で PDF を渡せます.
- **ツールボックス**: 結合, 分割, 画像への変換, 画像から PDF, 暗号化, 復号, テキスト抽出, ページの整理. タスクはバックグラウンドで順番に実行され, 進行状況は通知に表示されます.
- **AutoJs6 のファイルマネージャー**: PDF をタップするとビューアーで開き, 圧縮ファイル内の PDF も直接開けます. ファイルメニューから結合, 分割, 画像への変換, テキスト抽出, 暗号化, パスワードの解除を使えます.

### スクリプトでの使い方

AutoJs6 のスクリプトでグローバルモジュール `pdf` をそのまま使います. ページ番号は 1 から数え, ページ範囲は `'1-3,5,8-'` のように書きます:

```js
let info = pdf.info("./book.pdf");
console.log(info.pageCount, info.title);

let texts = pdf.text("./book.pdf", { pages: "1-3" });
console.log(texts[0]);

let img = pdf.render("./book.pdf", 1, { dpi: 200 });
images.save(img, "./page-1.png");
img.recycle();

pdf.merge(["./a.pdf", "./b.pdf"], "./ab.pdf");
```

- 各メソッドには Promise を返す `Async` 形式があります (例: `pdf.mergeAsync`). 同期形式は UI スレッドで呼び出せないため, UI スクリプトでは `Async` 形式を使ってください.
- 暗号化された文書を開くときはオプションに `password` を渡します. 失敗すると `code` 付きのエラーが投げられます (例: `PASSWORD_REQUIRED`, `PAGE_OUT_OF_RANGE`).
- Node.js では `require('autojs6:pdf')` で読み込み, Bun では `host.pdf` で使います. メソッドは同じで, すべて Promise を返します.

### 動作要件

- Android 7.0 以降. ビューアーとツールボックスは AutoJs6 なしで単独で使えます.
- スクリプトの `pdf` モジュールとファイルマネージャーの入口には AutoJs6 6.8.1 以降が必要です. スクリプトが読み書きするファイルは AutoJs6 が開くため, AutoJs6 にストレージの権限が必要です.
- ツールボックスとランチャーから開いたビューアーには, すべてのファイルへのアクセスが必要です. スクリプトでファイルを処理する場合, プラグインのこの権限は不要です.
- AutoJs6 でパッケージ化したアプリでも `pdf` モジュールを使えます. AutoJs6 6.8.1 以降でパッケージ化し, 実行する端末にこのプラグインをインストールしておく必要があります.
- Node.js スクリプトには Node.js Runtime プラグイン 2.2.0 以降が必要で, `project.json` の `node.permissions` に `files` を宣言します. Bun スクリプトには Bun Runtime プラグイン 0.23.0 以降 (Android 13 以降) が必要で, その設定画面で `pdf.control` をオンにします.
- スキャンページの文字を認識するには, 別途 OCR プラグイン (ML Kit OCR, Paddle OCR, Rapid OCR のいずれか) が必要です.

### よくある質問

**AutoJs6 なしでの利用**

ビューアーとツールボックスは単独で使えます. AutoJs6 が必要なのは, スクリプトで PDF を処理する場合だけです.

**プラグインセンターでこのプラグインが非対応と表示される理由**

スクリプトモジュールとファイルマネージャーの入口には AutoJs6 6.8.1 以降が必要で, AutoJs6 を更新すると有効にできます. それまでもビューアーとツールボックスは通常どおり使えます.

**最近のファイルの項目が開けない場合の対処**

ファイルが削除または移動された場合や, アクセスの許可が取り消された場合は, 項目をタップするとメッセージが表示され, 一覧から削除されます. "PDF を開く" からファイルを選び直してください.

スクリプトの完全な説明は [AutoJs6 ドキュメント > PDF](https://docs.autojs6.com/#/pdf), その他の情報は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Paper-PDF) を参照してください.
