3-Paper PDF는 AutoJs6 스크립트에 `pdf` 모듈을 제공하여 PDF 파일을 읽고, 렌더링하고, 병합, 분할, 생성, 암호화할 수 있게 하며, 양식 작성, 워터마크와 페이지 번호 추가, 파일 크기 압축도 할 수 있게 합니다. 단독으로 쓸 수 있는 PDF 뷰어이자 도구 상자이기도 하며, AutoJs6 없이도 사용할 수 있습니다.

### 시작하기

1. AutoJs6 스크립트에서 전역 모듈 `pdf`를 바로 사용합니다. 예시는 아래를 참고하세요.
2. 휴대폰에서 PDF를 보거나 처리하려면 런처에서 3-Paper PDF를 열고, 안내에 따라 모든 파일 접근 권한을 허용한 뒤 "PDF 열기"를 탭하거나 "도구"에서 필요한 처리를 고릅니다.
3. AutoJs6 파일 관리자에서 PDF 파일을 탭하면 3-Paper PDF 뷰어에서 열립니다.

### 주요 기능

- **읽기**: 페이지 수, 페이지 크기, 메타데이터, 암호화 상태; 페이지별 텍스트와 개요 (북마크); 텍스트 검색; 내장 이미지 목록과 내보내기.
- **렌더링**: 페이지를 이미지 객체나 PNG / JPEG / WebP 파일로 렌더링하며, 크기는 dpi, 배율, 목표 너비와 높이로 지정할 수 있습니다.
- **페이지 작업**: 병합 (북마크 유지), 분할, 추출, 삭제, 재정렬, 회전.
- **생성과 암호화**: 이미지, 텍스트, HTML로 PDF를 생성하고, 문서에 암호와 권한을 설정하거나 암호를 제거합니다.
- **편집**: 양식 작성, 워터마크, 페이지 번호, 머리글과 바닥글 추가, 파일 크기 압축, 제목, 작성자 같은 문서 속성과 개요 변경.
- **스캔 페이지 인식**: 설치된 OCR 플러그인으로 텍스트 레이어가 없는 스캔 페이지의 글자를 인식합니다. 스캔한 PDF에 텍스트 레이어를 기록해 검색 가능한 PDF로 만들 수도 있습니다.
- **뷰어**: 연속 스크롤, 핀치 줌, 썸네일, 개요, 검색 강조, 페이지 이동, 야간 모드. 다른 앱에서 "다음으로 열기"나 공유로 PDF를 넘길 수 있습니다.
- **도구 상자**: 병합, 분할, 압축, 워터마크 추가 등 13가지 도구. 처리가 끝나면 같은 처리를 스크립트로 만들 수 있습니다. 작업은 백그라운드에서 차례로 실행되며 진행 상황은 알림에 표시됩니다.
- **AutoJs6 파일 관리자**: PDF를 탭하면 뷰어에서 열리며, 압축 파일 안의 PDF도 바로 열 수 있습니다. 파일 메뉴에서 병합, 분할, 압축, 워터마크 추가 등의 처리를 쓸 수 있고, 검색 가능한 PDF도 만들 수 있습니다.

### 스크립트에서 사용하기

AutoJs6 스크립트에서 전역 모듈 `pdf`를 바로 사용합니다. 페이지 번호는 1부터 시작하며, 페이지 범위는 `'1-3,5,8-'`처럼 씁니다:

```js
let info = pdf.info("./book.pdf");
console.log(info.pageCount, info.title);

let texts = pdf.text("./book.pdf", { pages: "1-3" });
console.log(texts[0]);

let img = pdf.render("./book.pdf", 1, { dpi: 200 });
images.save(img, "./page-1.png");
img.recycle();

pdf.merge(["./a.pdf", "./b.pdf"], "./ab.pdf");
```

- 모든 메서드에는 Promise를 반환하는 `Async` 형태가 있습니다 (예: `pdf.mergeAsync`). 동기 형태는 UI 스레드에서 호출할 수 없으므로 UI 스크립트에서는 `Async` 형태를 사용하세요.
- 암호화된 문서를 열 때는 옵션에 `password`를 전달합니다. 실패하면 `code`가 있는 오류가 발생합니다 (예: `PASSWORD_REQUIRED`, `PAGE_OUT_OF_RANGE`).
- Node.js에서는 `require('autojs6:pdf')`로 불러오고, Bun에서는 `host.pdf`로 사용합니다. 메서드는 같으며 모두 Promise를 반환합니다.

### 요구 사항

- Android 7.0 이상. 뷰어와 도구 상자는 AutoJs6 없이 단독으로 쓸 수 있습니다.
- 스크립트의 `pdf` 모듈과 파일 관리자 진입점에는 AutoJs6 6.8.1 이상이 필요합니다. 스크립트가 읽고 쓰는 파일은 AutoJs6가 열기 때문에 AutoJs6에 저장소 권한이 필요합니다.
- 도구 상자와 런처에서 연 뷰어에는 모든 파일 접근 권한이 필요하며, 스크립트로 파일을 처리할 때는 플러그인의 이 권한이 필요하지 않습니다.
- AutoJs6로 패키징한 앱에서도 `pdf` 모듈을 쓸 수 있습니다. AutoJs6 6.8.1 이상으로 패키징해야 하며, 실행하는 기기에 이 플러그인이 설치되어 있어야 합니다.
- Node.js 스크립트에는 Node.js Runtime 플러그인 2.2.0 이상이 필요하며 `project.json`의 `node.permissions`에 `files`를 선언해야 합니다. Bun 스크립트에는 Bun Runtime 플러그인 0.23.0 이상 (Android 13 이상)이 필요하며 해당 설정 화면에서 `pdf.control`을 켜야 합니다.
- 스캔 페이지의 글자를 인식하거나 검색 가능한 PDF를 만들려면 OCR 플러그인 (ML Kit OCR, Paddle OCR, Rapid OCR)을 별도로 설치해야 합니다.

### 자주 묻는 질문

**AutoJs6 없이 사용하는 경우**

뷰어와 도구 상자는 단독으로 쓸 수 있으며, 스크립트에서 PDF를 처리할 때만 AutoJs6가 필요합니다.

**플러그인 센터에 이 플러그인이 호환되지 않는다고 표시되는 이유**

스크립트 모듈과 파일 관리자 진입점에는 AutoJs6 6.8.1 이상이 필요하며, AutoJs6를 업데이트하면 사용 설정할 수 있습니다. 그 전에도 뷰어와 도구 상자는 평소처럼 쓸 수 있습니다.

**최근 파일의 항목이 열리지 않을 때의 처리**

파일이 삭제되거나 이동되었거나 접근 허가가 취소되면, 항목을 탭할 때 안내가 표시되고 목록에서 제거됩니다. "PDF 열기"에서 파일을 다시 고르세요.

**작성한 양식 값이 뷰어에 표시되지 않는 이유**

Android 14 이하에서는 내장 뷰어가 평면화한 뒤에만 작성한 값을 표시합니다. 다른 PDF 앱에는 영향이 없습니다. 뷰어에서 확인하려면 작성할 때 "필드 평면화"를 선택하세요.

전체 스크립트 설명은 [AutoJs6 문서 > PDF](https://docs.autojs6.com/#/pdf), 그 밖의 정보는 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Paper-PDF)를 참고하세요.
