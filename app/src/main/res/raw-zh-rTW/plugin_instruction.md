3-Paper PDF 為 AutoJs6 指令碼提供 `pdf` 模組, 用於讀取, 算繪, 合併, 分割, 產生與加密 PDF 檔案, 也能填寫表單, 加上浮水印與頁碼, 壓縮檔案大小. 它同時是可以單獨使用的 PDF 檢視器與工具箱, 無需安裝 AutoJs6.

### 開始使用

1. 在 AutoJs6 指令碼中直接使用全域模組 `pdf`, 範例見下文.
2. 如需在手機上檢視或處理 PDF, 從啟動器開啟 3-Paper PDF, 依提示授予所有檔案存取權限, 然後輕觸 "開啟 PDF", 或在 "工具" 中選擇所需的處理.
3. 在 AutoJs6 的檔案管理員中輕觸 PDF 檔案, 即在 3-Paper PDF 的檢視器中開啟.

### 主要功能

- **讀取**: 頁數, 頁面尺寸, 中繼資料與加密狀態; 依頁擷取文字與大綱 (書籤); 搜尋文字; 列出並匯出內嵌圖片.
- **算繪**: 將頁面算繪為圖像物件或 PNG / JPEG / WebP 檔案, 可以依 dpi, 縮放比例或目標寬高指定尺寸.
- **頁面操作**: 合併 (保留書籤), 分割, 擷取, 刪除, 重排與旋轉頁面.
- **產生與加密**: 將圖片, 文字或 HTML 產生為 PDF; 為文件設定密碼與權限, 或移除密碼.
- **編輯**: 填寫表單, 加上浮水印, 頁碼與頁首頁尾, 壓縮檔案大小, 修改標題, 作者等文件屬性與書籤.
- **掃描頁辨識**: 藉助已安裝的 OCR 外掛辨識沒有文字層的掃描頁, 也可以為掃描檔寫入文字層, 產生可搜尋的 PDF.
- **檢視器**: 連續捲動, 雙指縮放, 縮圖, 大綱, 搜尋醒目提示, 跳頁, 夜間模式與全螢幕閱讀 (輕觸頁面收起工具列, 可在設定中選擇是否同時隱藏頁碼與系統列). 其他應用程式可以透過 "開啟方式" 或分享將 PDF 交給它.
- **工具箱**: 合併, 分割, 壓縮, 加上浮水印等 13 項工具, 處理完成後可以將同樣的處理寫成指令碼. 工作在背景依序執行, 通知欄顯示進度.
- **AutoJs6 檔案管理員**: 輕觸 PDF 即用檢視器開啟, 壓縮檔內的 PDF 也可直接開啟; 檔案選單提供合併, 分割, 壓縮, 加上浮水印等處理, 也可以產生可搜尋 PDF.

### 在指令碼中使用

在 AutoJs6 指令碼中直接使用全域模組 `pdf`. 頁碼從 1 開始, 頁碼範圍寫作 `'1-3,5,8-'`:

```js
let info = pdf.info("./book.pdf");
console.log(info.pageCount, info.title);

let texts = pdf.text("./book.pdf", { pages: "1-3" });
console.log(texts[0]);

let img = pdf.render("./book.pdf", 1, { dpi: 200 });
images.save(img, "./page-1.png");
img.recycle();

pdf.merge(["./a.pdf", "./b.pdf"], "./ab.pdf");
```

- 每個方法都有傳回 Promise 的 `Async` 形式 (例如 `pdf.mergeAsync`). 同步形式不能在 UI 執行緒呼叫, 介面指令碼請使用 `Async` 形式.
- 開啟加密文件時在選項中傳入 `password`. 出錯時擲回帶有 `code` 的錯誤, 例如 `PASSWORD_REQUIRED` 或 `PAGE_OUT_OF_RANGE`.
- Node.js 中使用 `require('autojs6:pdf')` 載入, Bun 中透過 `host.pdf` 使用, 方法相同, 均傳回 Promise.

### 執行需求

- Android 7.0 或更高版本. 檢視器與工具箱可以單獨使用, 無需 AutoJs6.
- 指令碼中的 `pdf` 模組與檔案管理員入口需要 AutoJs6 6.8.1 或更高版本. 指令碼讀寫的檔案由 AutoJs6 開啟, 因此 AutoJs6 需要儲存空間權限.
- 工具箱與從啟動器開啟的檢視器需要所有檔案存取權限, 指令碼處理檔案不需要外掛的這項權限.
- AutoJs6 打包的應用程式同樣可以使用 `pdf` 模組: 需由 AutoJs6 6.8.1 或更高版本打包, 執行的裝置上需安裝本外掛.
- Node.js 指令碼需要 Node.js Runtime 外掛 2.2.0 或更高版本, 並在 `project.json` 的 `node.permissions` 中宣告 `files`; Bun 指令碼需要 Bun Runtime 外掛 0.23.0 或更高版本 (Android 13 或以上), 並在其設定頁開啟 `pdf.control`.
- 辨識掃描頁的文字與產生可搜尋 PDF 需要另行安裝 OCR 外掛 (ML Kit OCR, Paddle OCR 或 Rapid OCR).

### 常見問題

**未安裝 AutoJs6 時是否可用**

可以. 檢視器與工具箱均可單獨使用, 僅在指令碼中處理 PDF 時需要 AutoJs6.

**外掛中心顯示本外掛不相容的原因**

指令碼模組與檔案管理員入口需要 AutoJs6 6.8.1 或更高版本, 升級 AutoJs6 後即可啟用; 在此之前檢視器與工具箱照常可用.

**最近的檔案中的檔案無法開啟時的處理**

檔案遭刪除, 移動或存取授權遭撤銷後, 輕觸該項目會顯示提示並將其從清單中移除. 請透過 "開啟 PDF" 重新選擇.

**填寫的表單值在檢視器中不顯示的原因**

在 Android 14 及更早版本上, 內建檢視器只有平面化後才會顯示填寫的值, 其他 PDF 應用程式不受影響. 需要在檢視器中查看時, 填寫時選擇 "平面化欄位".

完整的指令碼說明見 [AutoJs6 文件 > PDF](https://docs.autojs6.com/#/pdf), 其他資訊見 [專案主頁](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Paper-PDF).
