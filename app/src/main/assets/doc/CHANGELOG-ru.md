# v1.0.0

###### 2026/11/12

* `Подсказка` Предварительная версия для разработки: центр плагинов AutoJs6 может обнаружить плагин; чтение, отрисовка, операции со страницами, просмотрщик и модуль скриптов pdf ещё не готовы
* `Подсказка` Требуется AutoJs6 6.8.1 (6641) или новее (точная минимальная сборка будет указана после внесения изменений в хост)
* `Функция` Каркас плагина: протокол активации Wake, служба идентификации центра плагинов, служба возможностей PDF (версия контракта 1) и служба точки входа файлового менеджера
* `Функция` Главный экран: инструменты, ход задач, недавние файлы и предоставление доступа ко всем файлам (нужен только набору инструментов)
* `Функция` Набор инструментов из 8 инструментов: объединение, разделение (по диапазонам страниц или каждые n страниц), PDF в изображения (разрешение, формат, страницы), изображения в PDF (размер страницы, ориентация, поля), шифрование, снятие пароля, извлечение текста (в файл TXT), а также поворот, удаление и перестановка страниц по миниатюрам; обработка та же, что и у точек входа файлового менеджера
* `Функция` Задачи набора инструментов выполняются по очереди в активном сервисе и продолжаются после выхода с экрана инструмента; уведомление показывает ход и позволяет отменить, а результаты можно открыть в просмотрщике или отправить
* `Функция` Встроенный файловый браузер позволяет выбирать несколько файлов и создавать папки; системный выбор файлов тоже доступен
* `Функция` Экран настроек: папка вывода по умолчанию (Documents/3-Paper PDF), разрешение по умолчанию для PDF в изображения, язык, ночной режим, цвет темы, значок лаунчера, состояние разрешений, история выпусков и проверка обновлений
* `Функция` Проверка обновлений: вручную на экране настроек или автоматически при открытии главного экрана (не чаще одного раза в 12 часов); сведения о выпусках берутся из официального индекса плагинов
* `Функция` Светлые и тёмные значки для лаунчера и центра плагинов; по умолчанию лаунчер использует адаптивный автоматический значок (следует светлой или тёмной теме системы), а стили адаптивный светлый, адаптивный тёмный и прозрачный фон уже встроены, выбрать их можно на экране настроек
* `Функция` Один APK для всех ABI: обработка PDF не содержит нативных библиотек; единственная нативная библиотека входит в Jetpack Compose и выровнена по страницам памяти 16 KB
* `Функция` README, инструкции центра плагинов и журналы изменений на 10 языках, созданные из исходных файлов JSON
* `Зависимость` Добавлен PDFBox-Android 2.0.27.0 (текст, оглавление, изображения, операции со страницами и шифрование)
* `Зависимость` Добавлен Jetpack Compose BOM 2026.09.00 (экраны плагина)
* `Зависимость` Добавлен Navigation Compose 2.10.2
* `Зависимость` Добавлен Material Color Utilities (MaterialKolor) 4.1.1 (цвет темы экранов плагина)
* `Зависимость` Добавлен AndroidX Core KTX 1.18.0
